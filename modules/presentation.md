# PPT配图模块

常用画法先查[模块推荐](../references/style-recommendations.md)，再由共享路由按内容选择。封面、解释与背景分别控制强度。

沿用演示文稿目标、逐页要点与既有模板，先确定每页听众应理解的一句话，再判断图片承担什么作用。完整PPT的内容、排版和交付由演示文稿流程负责。图像组织依据材料中的问题和关系，不沿代码目录或风格目录堆积页面；工程样例与实际效果沿用来源状态。

## 按当前难点深入

页面缺少重点、证据或整套节奏时读[页面组织](../references/presentation-composition.md)；中文标题、投影识读与文件编辑需求见[文字与输出](../references/typography-and-production.md)；缺槽位参考、背景、独立装饰或符号时见[海报/PPT素材](../references/design-materials.md)。已有模板与手工修改优先，按需要取用，不把全部参考变成必走流程。

## 按页分配图片职责

| 图片角色 | 需明确的内容 | 方法要求 |
|---|---|---|
| 封面、章节主视觉 | 主题身份与重点 | 有辨识度，给实际标题区域留空间 |
| 背景 | 文字和图表承载区 | 安静区域对应实际排版，默认不生成正文 |
| 概念或机制图 | 对象、作用、因果和层级 | 图形语义清楚，标签准确 |
| 流程或架构图 | 节点、分支、职责和数据流 | 先确定关系，再安排布局与箭头 |
| 对比或演化图 | 条件、阶段与比较维度 | 使用共同基准，区分机制和实测 |
| 场景示意图 | 应用环境中的位置和交互 | 对象与交互来自项目，有解释作用 |
| 透明素材或装饰 | 独立对象、角标和分隔元素 | 按占位比例设计，透明需求使用真实透明背景 |

图片数量由表达作用和用户要求决定。多图时内部明确所在页、目的、源信息、占位比例、透明需求与文字承载方式，不让用户逐字段填写。

整体视觉未定时，按[方向流程](../references/art-direction.md)先出三个代表性封面或整体概念预览。选定后再生成背景、概念、流程、场景等细分图。已有选定方向、模板或明确自主决定授权时直接继续，不再请用户逐图挑选画风。

## 将关系组织为图

- 流程先确认节点、顺序、分支条件和反馈方向；架构先确认职责、边界与连接意义。省略不影响本页理解的细节，不靠装饰箭头补关系。
- 比较先确定共同条件和维度。有真实数据时按数据绘制；没有数据时展示机制或方案差异，不生成貌似实测的曲线。
- 场景图使用项目相关对象和交互；概念图以形状和空间关系直接解释材料中的概念。
- 背景按实际文字区安排安静区域；独立素材便于排版，真实透明背景不画棋盘格。

按本页目的选取整页图、左右图文、并列比较、阶段展开或结论强调等布局。布局承担信息组织，整套主题承担颜色、字形和表面语言；同一主题下可以复用多个布局。根据对象和文字区决定填满裁切、完整显示或分区承载，流程关键节点不随封面裁切方式被截掉。参考[布局与主题的借鉴](../references/design-patterns.md)。

## 整套一致性

模块确定哪些页共享视觉系统、哪些对象或角色需一致、哪些区域承载文字。网格、Bento、分区、投影、节点关系和阅读顺序属于方法；冷暖、线条、材质和字体气质交共享路由。已有品牌或模板参数作为输入约束。

按[当前偏好](../references/preferences.md)分别判断各角色的风格与强度：封面可有较强视觉表现，解释图保持关系清楚。不同结构可共享颜色语义、线条层次和字形气质，不机械覆盖封面纹理，也不为显得多样逐页换色盘和媒介。

在项目里保留选定参考和共同视觉参数，再按角色生成提示词。成套符号统一线宽、端点、圆角、填充及视觉体量；主视觉、背景与透明对象保留可分别使用的文件。真实界面与证据材料优先保持原始身份，素材复用与外部来源按[成套素材规则](../references/asset-system.md)处理。

## 页面与交付检查

在实际页面检查裁切、留白、遮挡、对比和投影尺寸下的识读。背景用实际标题、正文或图表叠放检查；流程与概念图逐项核对节点及箭头。PPT标题、正文和需编辑数值交幻灯片排版；整页生成图片只用于用户明确需要的场景。

用户要完整PPT时继续完成演示文稿，不只交一组图片；用户要审阅方向时可生成整页视觉示意，标明审阅用途。最终素材保存在项目中，引用对应文件，透明素材保留正确透明度与边界；保留实际提示词。

用户指定包豪斯等名称时，接收共享路由拆出的组织建议，仅在本页内容与既有约束允许时采用；网格、字图层级与留白仍由模块负责。名称对应的色彩、线条、造型、光影、材质与字体气质交路由，不能用材质替代信息组织。
