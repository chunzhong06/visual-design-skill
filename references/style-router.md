# 共享风格路由

读取模块确定的内容、图片角色、组织方法、准确文字、投放尺寸与整套约束，以及[当前偏好](preferences.md)。输出视觉语言、六维参数和表现强度；名称中的组织建议交方法模块判断，不改事实、用户指定布局、投影、连接关系或生图后端。

## 模块推荐作为用途入口

按[推荐说明](style-recommendations.md)与[推荐元数据](../styles/module-recommendations.json)定位少量候选。科研正文优先三套技术表达；PPT和海报各有六种常用推荐，其余配方条件适用。先确定正文/Teaser/汇报/宣传角色；推荐不覆盖用户明确要求、项目既定方向与准确内容。科研请求不因图库图标丰富而变成图标式概览。

## 从任务取得选择条件

先识别这张图承担主视觉、背景、解释、场景还是独立素材；明确哪些区域有标签、箭头或正文，哪些区域允许强纹理与光影。还需判断想传递的气质、真实材质的重要性、可接受的概括程度与已有项目视觉设定。信息密度按实际受风格影响的区域判断，不能仅凭整页文字多就排除其中一块印刷主视觉。

当前明确参考、品牌或选定方案优先。用户只指定Bento、等距、流程图或16:9时，它们分别作为模块的版式、投影、结构和画幅输入，不当作风格匹配结果。将风格参考与内容参考的用途分开：前者继承指定视觉特征，后者按要求保留对象身份和准确内容。

## 同一条路由先解释名称

用户用流派、界面或情绪名称限定风格时，按[解释规则](aesthetic-interpretation.md)读取[名称索引](../aesthetics/index.md)及命中的卡片。先确认该词是肯定要求、否定、比较、引用还是局部借鉴，再向模块给出有条件的组织建议，向视觉选择给出必要特征、六维参数与可选配方。必要时可用离线别名定位脚本；返回的是提及，不是用户选择。

已有配方的aliases仅用于媒介检索，不取代名称卡。例如波普不等于漫画网点、包豪斯不等于旧纸半调，蓝图称呼也不强制蓝底、三视图和装饰刻度。保留名称要求而配方有冲突时，只取相容参数或自主设计，不为命中配方忽略用户限制。

没有名称要求时直接按内容选视觉，不必先选一个艺术流派。未知名、宽泛词或混合名称依解释规则处理，不自动安装外部项目。本层仍属于共享路由，不增加模块或另一套生成流程。

## 表达策略先于媒介

先由模块说明本图要让人记住的产品价值、内容证据和项目气质，比较文字主导、真实对象/产品主导、场景或关系解释等可用表达。由这些条件选择媒介；不要先选用户偏好的纹理，再寻找可以塞进该纹理的图标。

三案应从表达策略或主要视觉对象拉开差异，不用同一权限图、同一卡片阵列或同一符号拼贴换材质凑三案。海报不默认承担完整教程；PPT内部解释图才按需要展开关系。一个题材不对应一张固定配方，安全、科研、AI等关键词也不自动触发终端、霓虹或文件夹图标。

## 先筛适配，再比较偏好

1. 已有选定方案时从项目恢复六维参数和角色分工，不因库更新重新选案。用户分别选择海报和PPT方向时保留各自设定，通过共同颜色语义、字形或线条建立关联。
2. 无既定方向时用[分组索引](../styles/index.md)定位候选；按字段筛选可读[配方元数据](../styles/catalogue.json)。`aliases`帮助检索，`roles`和`density`提供适配线索，`caution`说明代价；它们不代替语义判断。不能仅凭“科技、自然、可爱”等主题词或上游项目名称命中。
3. 按已读取的个人设定排除明确拒绝的视觉语言，表现方式限制交模块处理。不把某个项目不适合扩大成全局禁用，不把一种具体画法扩大为全部媒介。参考中出现人物、标志、条码或原文，不因匹配画风而一起复制。
4. 比较表达需要、角色、识读、材料真实感和整套协调。通常只深入读取2至4张相关卡，无需载入全部卡片全文。喜欢的风格在适配条件相近时优先，不覆盖准确性或把所有输出变成印刷质感。
5. 已有配方和自主设计是平等选项；相关配方只有部分合适时，可提取必要视觉参数或直接自主设计。无须排除全库才能自主设计，也不为完成任务自动搜索、安装或切换后端。

## 先核适配，再比较偏好

风格候选先满足当前要求、准确对象、必要关系、实际识读和模板身份，再看它是否支持本图主张。使用者偏好的媒介只在这些条件相近时优先；不因“用户喜欢”把不合项目身份的候选塞进三案。其他视觉语言按内容正常参与，不需要逐项评选。已有配方仅部分相容时提取参数或自主设计，不要求把全库逐一排除。

内部用一句话说明“这张图以什么让内容被看见”，再说明视觉怎样支持它。对于真实软件产品，可用原界面、准确文字或有依据的使用场景；没有依据的通用芯片、神经网、玻璃球和工业设备不能替代产品身份。技术主题也不自动等于黑底蓝光，文化主题不自动等于水墨。

| 用途条件 | 可查的参数 | 采用时的判断 |
|---|---|---|
| 文字主张本身有传播力 | 高对比重字形、中性无衬线编辑 | 关键字完整，中文不强行压窄，版式交海报模块 |
| 产品对象或材料品质重要 | 棚拍产品质感、精密实体渲染、编辑摄影 | 对象与结构有依据，软件优先保留真实界面 |
| 需要干净而有身份的工作图 | 中性无衬线编辑、纯净几何色面、精密线描 | 精简装饰并保留具体对象，不退回空白模板 |
| 需要叙述、品质或文化气质 | 精致衬线编辑、摄影纸本拼贴、笔墨与颜料 | 题材、字形与识读相容；不虚构引语、档案和细节 |
| 需要强节奏与视觉张力 | 光学条纹图形、重字形、制版印刷 | 条纹和肌理避开必要文字；不制造数据波形 |
| 清透或空间材料确实服务主体 | 清透折射材质、精密实体渲染、哑光立体 | 折射/阴影不改变文字与关系，不全页玻璃卡片化 |

## 同一方向按角色减弱

封面与海报建立身份；正文背景降低细节并预留安静区；机制与比较图保留必要关系；证据页保持原材料和真实图表。固定色彩含义、字形和轮廓语法，按内容改变构图及表现强度。无需把每页都画成海报，也不为展示风格数量逐页换媒介。

这些是共享路由中的选择条件，不增加第二层路由。素材文件只帮助实现，不能反过来要求内容套现成图。需要时按[案例转译](case-patterns.md)理解来源做法。

## 按表达需要检索

| 当前需要 | 可先查的组别或处理 | 主要判断 |
|---|---|---|
| 强主视觉、制版触感、宣传张力 | 制版与印刷、摄影与光学处理 | 主题对象是否清楚，网点/刻线是否妨碍文字 |
| 设备、材料、真实场景或实际人物 | 摄影与光学处理 | 依据与示意身份、对象可信度及光线；真实证据保留原始材料 |
| 密集节点、比较关系或小标签 | 精密线描、简洁平面插画，或自主低纹理处理 | 节点、连接、颜色语义和最终尺寸识读 |
| 亲切、手工、文化或生活叙事 | 线条与手绘、笔墨与颜料、纸本拼贴 | 笔触和材质怎样服务内容，是否丢掉关键识别特征 |
| 材质展示、独立对象或有体积的封面 | 立体与表面材质 | 反射、厚度、透明与毛边是否影响使用；不把材质当成技术先进性的证据 |
| 承载正文的背景或低干扰装饰 | 柔光与氛围，或按内容自主设计的平面底色 | 文字区反差、焦点、裁切与细节强度 |

这些是入口，不固定题材和画风的对应。水彩也可画设备，印刷也可服务技术项目；最终由这张图的表达需要与识读条件判断。

## 从候选到三案或成套图片

整体视觉未定时，按[方向流程](art-direction.md)生成三张代表性预览。三案在媒介、线条、材质或主视觉处理上有可见差异，不把同一纸纹换三种颜色当作三种方向。每案都满足相同事实与用途，先说明可见特点，再等用户选择；不批量预生成依赖选择的细分图。

选定后固定项目的必要视觉参数与颜色语义，按图片角色控制强度。封面可以强表现，背景保持安静，解释图保持清楚；不为展示库的丰富度逐页换风格。混合媒介时写清各自负责的区域或对象，避免无目的叠加纸、玻璃、油彩和霓虹。

## 六维输出与生成

内部简短保留配方标识或自主设计、适配理由、必要六维参数、使用强度和整套约束。无需让用户逐字段确认。

| 维度 | 要明确什么 |
|---|---|
| 色彩 | 冷暖、色盘、反差、饱和度与颜色所表示的对象/状态 |
| 线条 | 粗细、规整程度、边缘软硬、描边、排线或笔触 |
| 造型 | 几何或有机、写实或概括、轮廓与识别特征 |
| 光影 | 平涂、硬边、柔光、体积、反射或折射 |
| 材质 | 纸、墨、颜料、摄影表面、哑光、金属、玻璃或织物 |
| 字体气质 | 几何、中性、衬线、手写或书法；无字素材不强加字体 |

将来源内容、模块方法和视觉参数合成具体提示词，再按当前imagegen流程执行。字号、位置、阅读路径、投影、节点和箭头继续由模块负责。生成后在实际尺寸下检查；问题影响哪张或哪一层就定向修改。成功单图不自动登记成新画风，项目选择不自动变为全局排除或排序。
## 科研用途的条件路由

科研模块传递图意、科学骨架、正文/Teaser/汇报用途、密度、最终尺寸和精确层要求。按需读取[科研视觉预设](research/visual-profiles.md)，复用已有配方或自主设计。预设仍归本共享路由；Token、张量和协议等[科学对象](research/visual-vocabulary.md)由模块选择，双流/闭环/多面板属于组织方法。

先满足科学语义、必要连接、当前参考和实际尺寸识读，再比较视觉表现与偏好。宣传主视觉的个人材质偏好不自动给论文架构图加权。低纹理并非全部科研任务的唯一画法；Teaser、场景与有依据的局部科学插画可以更丰富，表现强度按角色调整。

科研三案保留同一份必要对象、标签和关系，可比较不同视觉表达与符合结构的布局，不用改算法、增删路径或暗示不同结果制造差异。真实数据图的几何和数值由绘图流程负责；本层统一视觉参数，不寻找或切换技能/生图后端。
