# 计算机科研视觉词汇

为关键输入、独特操作、中间表示和输出选择局部图解；普通模块可以只有标签，不要求每框一个图标。下面是可选表达，不据画法推断真实结构。

| 科学对象 | 可见表达 | 必须由来源决定 |
|---|---|---|
| Token与序列 | 小单元、位置对应、分组或选择 | 文本、长度、掩码、规则 |
| 嵌入与矩阵 | 列向量、格、索引到表示 | 维度、取值、实际分布 |
| 特征与张量 | 薄片堆叠、网格、体积 | 通道、层数、分辨率、比例含义 |
| 注意力 | Q/K/V关系、匹配、头的分工 | 权重、真实热图、头数、方向 |
| 编解码与多模态 | 形态变化、分支到共同表示 | 融合顺序、共享、交叉与输出范围 |
| 图传播 | 邻域高亮、方向消息 | 邻接、轮次、节点/边属性 |
| 检索与索引 | 文档块、查询、候选、排序 | 来源、检索/重排、样例与权限 |
| Cache与记忆 | 读写端口、历史与当前 | 生命周期、更新、持久化与状态 |
| 训练与优化 | 参数状态、损失接口、反馈 | 冻结/可训练、梯度、目标和停止 |
| 路由与专家 | 有条件分支、选择与合并 | 数量、门控、稀疏性与权重 |
| 扩散与迭代 | 状态变化、条件更新、循环 | 步数、时间方向、噪声与真实结果 |
| 空间与视觉 | 视锥、射线、点云、坐标 | 几何、标定、位置、重建/采样结果 |
| 系统与资源 | 服务器、队列、端边云 | 部署、数量、带宽/时延与边界 |
| 安全与协议 | 泳道、信任区域、消息 | 威胁、密钥、方向、权限与异常 |

## 生图中怎样使用

描述对象代表什么、位置、连接、需要具体化的部分和准确标签。例如“查询条指向文档候选，只有选中候选连向下一模块”，比“高级检索图标”更有用。输入、中间操作和输出可形成一个局部科学组合。

概念格纹、数据栈和符号性连线保持示意身份。注意力、嵌入散点、谱图、预测与性能曲线若表示观察结果，必须来自实际材料。通用素材不携带真实参数或实验结论。

现成注意力符号、专家扇形或编解码图仅作语义锚点，固定图形中的线/层数量不能当成真实架构。含义不合时修改可编辑几何或让生图按结构重画，不更改研究描述来适配素材。

## 成套图形

复用对象轮廓、颜色语义、字形与线条。二维关系可搭配有意义的特征体积或场景，说明各自职责，材质不遮挡标签与连接。图例解释当前图确实依赖的编码，按需保留。素材入口见[材料使用](materials.md)；更丰富的库增加可用表达，不增加每张图的必需图标数。

## 专业符号怎样参与解释

在输入、独特操作和输出处主动考虑合适的图形，避免所有对象都退化成同样的文字框。识别符号帮助辨认表格、模型包、检查点和记录；局部图解帮助看懂列选择、切块、读写或组件替换。两者和标签、连接协同工作，不以每框一个图标为目标。

本地补充了样本表、缩放变换、特征列选择、参数化预测器、完整模型流水线、成对证据和方法记录七种可编辑对象。可在共享入口用中文名称或preprocessing、feature selection、paired evidence搜索。通用缩放符号只表示变换，不说明采用均值/标准差还是中位数/IQR；需表达这一区别时根据方法画局部机制。模型包不暗示神经网络，预测器局部和完整模型包使用不同图形；锁表示候选身份固定时配准确标签。

专业项目参考：[ML Paper Icons](https://github.com/Mizar77/ml-paper-icons)提供按研究场景整理的通用符号；[CV/GFX/ML Icons](https://github.com/tovacinni/cv-gfx-ml-icons)提供领域对象；[NN-SVG](https://github.com/alexlenail/NN-SVG)支持参数化网络架构图。按当前研究对象选择；网络层、边权与卷积体积只有来源支持时采用。上游自称publication-ready不是当前图已通过科学核验的证据。
