# 科研图的生成、组合与核验

由[内容提取](source-to-figure.md)形成科学骨架，[组织方法](composition.md)决定表达，共享路由决定六维参数。这里编译已作出的决定并检查实际产物，不在提示词阶段重新创造科学设计。

## 传递给现有生图插件

按需要合成为一份可执行、无冲突的提示词：

1. 用途、图意、读者应理解的关系、画幅和最终尺寸。
2. 整体组织、阅读路径、区域分工、主次与总览/放大/面板对应。
3. 具体科学对象、必要节点、输入输出与全部必要连接，含箭头、分支、反馈和边界的语义。
4. 准确可见标签、符号、图例及例子。区域编号和制作指令未列入可见文字时不得入图，图注通常留在图外。
5. 六维参数、颜色语义、对象画法、留白与字体层次，以及参考只借鉴哪些维度。
6. 必须保留和禁止新增内容，包括未获依据的模块、数字、结果、维度、权限和快捷连接。

标签语言由论文、投稿和用户要求决定。公式与数学符号需准确，复杂公式/高密度文字可用后续原生排版，不缩成微小字。局部图解说明可见构成与科学作用。

参考图先查看并区分结构、内容与风格用途。按当前imagegen规则提供正确图片输入，不声称文字描述等于已传入参考图。

## 数据与精确层

曲线、统计、数值矩阵、实际激活和注意力图依据真实数据，保留变量、单位、条件、处理与不确定性来源。纯示意保持示意身份。

混合图先完成数据面板，生图处理机制、场景或独立插画，再保留原数据图进行组合，统一字形、线宽、颜色和面板。原始截图和证据同样保持来源身份，不让生图重绘成“更好看”的结果。

可编辑结果按任务使用SVG、draw.io、PPT原生对象或可用工具；生图参与视觉与插画，精确标签、公式和连接可分层。只有保留原生对象才称可编辑，PNG封装进PDF/SVG不能代替矢量重建。

## 实际看图

打开最终分辨率并在目标栏宽/页面检查。对照来源与规格，再评外观；科学错误不被美观评分抵消。

| 检查 | 观察什么 |
|---|---|
| 对象 | 必要对象存在、身份对应、共享/重复准确，扫描额外模块 |
| 全部连接 | 逐边找起点、终点、方向、线型、标签和条件；扫描多余箭头与捷径 |
| 主路径回读 | 从输入沿图走到输出，读出必要分支、合并和反馈，与来源比对 |
| 文字与符号 | 名称、大小写、下标、公式、维度、单位、面板、图例逐项对应 |
| 论点与证据 | 支持指定主张，例子有效，计划/实测/示意清楚，图注对应 |
| 版式与识读 | 无穿字、遮挡、悬空，实际尺寸清楚，颜色有必要冗余编码 |
| 视觉符合度 | 实际轮廓、色彩、光影、材质和字形符合已选方向 |

复杂图按[规格](figure-spec.md)逐项核对。看不清时记待核验；API成功、规格校验与上一版图片都不替代当前目检。采用节点/路径和成图反读思想，不声称未部署的自动识图器已运行。

## 修改、停止与交付

定位内容、组织、文字、风格或导出缺陷，先更新结构决定，再给定向编辑指令，保留正确内容与关键关系，不堆互相冲突的补丁。修改后复查受影响区域及必要全局路径。

有限迭代至满足本次要求，不为自评分持续重画。生图无法稳定控制精确标签或连接时采用分层标注/原生几何，并查看最终导出；科学缺口未解决时指出具体内容。

交付最终图、实际提示词、必要图注；数据图附映射和绘图源文件，原生重建附来源。临时检查图与脚本集中存放、完成清理，保留必要实测证据。来源、输入结构检查、实际目检和用户采纳分开记录。
