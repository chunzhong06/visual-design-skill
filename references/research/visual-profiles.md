# 科研视觉预设

属于[共享路由](../style-router.md)的条件参考，不另起模块或第二套路由。先由科研模块确定图意、骨架、用途、密度与尺寸，再让六维参数参与构图。可组合、部分借用或自主设计，与媒介配方不相加计算画风数。

参数根据实际论文图与已读项目独立整理，来源见[论文图设计](paper-visual-design.md)和[来源说明](../sources.md)。会议名称不是统一美学规定，固定布局、节点数与科学内容不从参考继承。正文优先前三套；后两套随具体对象与用途采用，细节充实先由科学内容确定。

| 预设 | 六维参数 | 适用与控制 |
|---|---|---|
| 中性精密矢量 neutral-technical | 色彩：浅底、中性与少量强调；线条：准确、主次统一；造型：干净几何和科学对象；光影：平涂；材质：低纹理；字体：中性标签与对应数学字形 | 密集架构、协议、严格标注。借精密线描/简洁平面，不自动加图纸刻度 |
| 柔彩语义分区 soft-semantic | 色彩：低饱和浅色与可读深色；线条：细而有层次；造型：具体表示与操作，容器从简；光影：平涂；材质：平整；字体：中性标签与正确数学字形 | 多模块方法、总览与局部机制。颜色映射职责/状态，结合位置、形状或标签，不做图标阵列与浮雕卡片 |
| 高反差几何技术 high-contrast-geometric | 色彩：明确明暗与信号色；线条：规整硬边；造型：清楚几何；光影：平面/硬边；材质：干净色面；字体：紧凑、重点明确 | 强调关键结构、路径与差异。借硬边平面/线描，不加旧纸、半调或霓虹 |
| 清爽对象插画 scientific-illustrated | 色彩：受控多色；线条：统一且可读；造型：保留方法相关身份；光影：平涂/轻柔光；材质：干净；字体：标签连贯 | 场景、模态、Teaser与局部机制。对象有明确科学作用，不默认卡通人物 |
| 克制哑光空间 restrained-spatial | 色彩：克制冷暖；线条：实体边与准确连接；造型：有意义体积；光影：柔和受控；材质：低反光；字体：平面可读 | 特征体积、设备、几何与独立对象。空间只表达有依据含义，不整图堆浮雕卡片 |

正文小尺寸和多连接优先识读，但不要求所有图同一种外观。Teaser或汇报可用更强插画与层次，仍保留科学关系。图组共享颜色语义、对象、线条与字体，按角色调整强度，不每图重选或复制构图。

海报中的纸纹、半调与木刻喜好不自动迁入论文图；当前参考或明确要求只作用于相容维度。灰度、色觉识读、矢量输出与最终栏宽属于输出约束，具体出版要求查目标会议当期模板，不把“NeurIPS色盘”或自评分数写成标准。
