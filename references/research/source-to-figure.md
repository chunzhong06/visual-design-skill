# 从来源到科学图形

先明确读者看完应理解什么关系，再提取科学骨架；视觉选择随后共同参与布局和对象表达。只读相关章节，记录可回查位置，不要求用户填写规格。

## 来源与图意

| 来源 | 提取重点 | 边界 |
|---|---|---|
| 摘要、引言、贡献 | 问题、关键方法作用、需解释的区别 | 主张不自动当成实测结果 |
| 方法、算法、公式 | 操作、顺序、分支、条件、状态与符号 | 区分设计、推导、实际执行与因果 |
| 图注及邻近正文 | 图的范围、术语、例子、面板 | 冲突需核实，不任取其一 |
| 代码与配置 | 当前路径、内部操作、共享、重复与维度 | 只跟踪核验所需入口，不为画图运行不明代码或安装模型 |
| 数据、日志、原始图像 | 数值、条件、单位、实测示例 | 保留处理来源，不从视觉样图反推结果 |
| 参考图 | 指定的结构或外观经验 | 不继承其算法、数字、标签或权限 |

每图用一句话说明问题、回答与证据，区分必须出现、支撑理解和适合放图注的内容。图组按论点分工，不固定图数。论文确定叙事范围，代码核验实现；二者分歧时记录位置，按本次要展示设计还是实现处理。

## 对象与关系

1. 标出真实输入、处理、输出、参与方、状态与贡献模块；跨面板对象保留稳定身份。
2. 对每条必要连接记录起点、终点、含义、方向和条件；区分数据、控制、依赖、消息、梯度、反馈、包含与因果。
3. 数据传递不自动成为因果，空间邻近不产生边；建议、验证与执行分清。
4. 保留串/并行、加法/拼接/乘法/门控、残差/跳连、共享/独立参数。符号按本图词典使用，同符号不得同时代表不同操作。
5. 仅表达材料支持的训练、推理、离线、在线与评估路径。必要时记录禁止捷径，例如只提供建议的角色不能直达执行端。

未知结构先查材料。只有影响科学含义的缺口才追问，其余明确省略或采用不损失含义的抽象。设计图可以没有实测结果。

## 层次与细节

整体层解释协作，模块层展开关键创新，算子层仅保留有助论证的操作。同构重复可用×N，N须有依据；共享模块不能画成独立参数。总览与局部展开保持名称、接口和对象对应，放大引出线不变成计算边。

细节优先给有意义的输入形态、中间表示、关键操作、条件和输出。需要科学对象时读[视觉词汇](visual-vocabulary.md)，不以惯常Transformer/CNN补全未知结构。复杂或反复修图的结构按[图规格](figure-spec.md)记录；规格不能代替查看成图。
