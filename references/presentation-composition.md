# PPT：页面目的、配图分工与成套节奏

沿用现有演示文稿流程与模板。先确定每页让听众理解的一句话，再判断需要证据、关系、场景还是强调；不用风格目录决定页数。讲演、阅读型材料与备查页允许不同密度。

## 按页面问题组织

| 页面任务 | 适配组织 | 生图的作用与边界 |
|---|---|---|
| 建立主题身份 | 封面、单一对象、场景、文字主导 | 生成主视觉并给准确标题留区域 |
| 引入章节 | 简短主张与视觉锚点 | 复用主题语言，降低制作量；不每章换风格 |
| 解释问题 | 场景、实际对象、局部放大 | 场景图解释所处环境，真实问题证据沿用原件 |
| 提出结论并支持 | 结论标题＋一组视觉证据 | 依据事实选择截图、照片、图表或机制图 |
| 说明产品 | 完整界面＋关键区放大／实际对象＋标注 | 原始界面准确保留；生成背景和说明素材可辅助 |
| 解释过程 | 顺序、分支、闭环、泳道 | 先核对节点和箭头；需编辑的关系使用原生对象 |
| 解释体系 | 层级、职责、边界、连接 | 依据真实结构，避免通用大脑、芯片或机器人代替说明 |
| 比较选择 | 共同条件、并列对象、证据表 | 保留共同比较维度；真实指标交绘图／排版 |
| 说明时间或演进 | 分阶段时间轴、前后状态 | 时间点来自材料，阶段多少由内容决定 |
| 表达规模与数值 | 重点指标、分布、趋势、表格 | 真实数据制作几何，风格仅统一配色和字体 |
| 解释空间／交互 | 场景、剖面、局部展开 | 必要对象与位置有据，投影不冒充画风 |
| 形成记忆与行动 | 核心结论、明确下一步、简短联系方式 | 沿用主题，联系与行动信息准确 |

不是每页都需要新图片。已有清楚证据或原生图表时，继续设计其层级与标注；不要为完成“使用生图”把每页加装饰图。用户要求生图配图时，选择确有表达作用的主视觉、机制、场景、背景或独立对象。

## 按用途建立页面家族

封面与章节形成辨识度；解释页承载逻辑；证据页承载事实；比较页支持判断；结尾收束主张。以上是可以复用的页面家族，不是固定章节或页数。

锁定的共同参数包括底色与语义色、标题及正文字形、边距与间距节奏、线宽与圆角、照片/插画处理。每页可按内容采用全幅、左右、上下、并列、局部放大或多面板；变化应有表达理由。不要把整套变成同一种圆角卡片，也不靠逐页换色维持新鲜感。

封面选定风格后，至少判断解释与证据页怎样降低表现强度，再展开细分素材。印刷封面不要求文字区带网点；光感封面不要求流程节点发光；空间封面不把真实数据画成立体柱体。需要时先试一页内容最密集的代表页。

## 把图片交给实际页面

在内部配图清单中仅保留有用字段：页或用途、这张图说明什么、来源对象和关系、占位比例、放置范围、准确文字由谁承载、完整显示还是裁切、透明需求及文件。可用归一化坐标表达主体区和文字安全区，不强制用户填表。

背景本身无正文，安静区域对应实际标题和正文；将真实文字与图表叠放后核验。图片中已经存在的标题不要在幻灯片上重复。独立对象保持完整轮廓，按最终放置比例观察边缘和阴影。

素材 `layout-guide` 只提供几何起点，不强制固定数量和比例。对照图、流程图和证据截图通常完整显示；人物/场景主视觉可围绕焦点裁切。向演示文稿流程交付共同参数、文件映射与关键裁切要求，继续完成用户要求的PPT；所用具体导出工具沿当前环境。

原则参考 [Duarte](https://www.duarte.com/blog/4-presentation-design-principles-to-live-by/)、[Assertion–Evidence](https://writing.engr.psu.edu/assertion_evidence_EA.html)、[Slidev布局](https://sli.dev/builtin/layouts.html)及[Marpit图片](https://marpit.marp.app/image-syntax)。采用信息与证据、布局与主题、裁切与完整显示的分工，不照搬各项目的字体数量、页数和工具工作流。
