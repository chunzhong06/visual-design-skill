# 按模块进入风格库

这是共享路由的用途索引，不增加路由层，也不把推荐当成题材到风格的强制映射。用户明确参考、已选项目方向与实际内容优先；已有配方和自主设计共同参与。推荐元数据见[模块索引](../styles/module-recommendations.json)，完整库见[25张参数卡](../styles/index.md)。

## 科研：正文优先三套，另两套按对象使用

| 优先表达 | 适合什么 | 视觉重点 |
|---|---|---|
| 中性精密矢量 | 论文方法、系统、协议和评估流程 | 精确主次线条、中性标签、具体操作与清楚接口，保留必要符号 |
| 柔彩语义分区 | 多模块架构、总览与局部机制 | 低饱和分区表达职责/状态，具体表示与操作为主体，容器从简 |
| 高反差几何技术 | 方法差别、关键分支和约束 | 硬边对象、可辨轮廓与局部强调，颜色和形状有含义 |

清爽对象插画用于有实际对象的场景、局部机制和Teaser；克制哑光空间用于确有体积、几何或设备意义的对象。两者条件适用，不把整个系统变成图标阵列或浮雕卡片。

这些表达复用精密线描、中性编辑、简洁平面、纯净几何、哑光立体等媒介参数；它们不是新增的五个艺术流派。先读[论文图设计](research/paper-visual-design.md)和[科研参数](research/visual-profiles.md)。实测数值图的几何由真实数据与绘图流程确定。

## PPT：六种常用推荐

| 配方 | 首选角色 | 采用条件 |
|---|---|---|
| 中性无衬线编辑 | 工作汇报、证据与整体主题 | 层级、真实材料和重点明确，避免默认卡片阵列 |
| 简洁平面插画 | 概念、过程和应用解释 | 对象语义与必要关系清楚 |
| 精密线描 | 架构、流程和技术比较 | 小标签与箭头可读、端点准确 |
| 哑光立体 | 封面、章节与独立对象 | 体积服务内容，阴影不遮关系 |
| 纯净几何色面 | 章节、主题图形和简洁比较 | 色彩有分工，页面按内容组织 |
| 几何半调印刷 | 内容适配的封面与章节视觉 | 用户偏好在适合区域优先；解释与证据区降低纹理 |

柔光渐变作为背景参数，编辑摄影作为真实对象/场景处理，衬线编辑用于品质与出版气质，硬边高对比用于需要力度的局部；不必为这些角色逐页另建主题。封面、解释和证据共同保持颜色语义与字形，按角色变化强度。

## 海报：六种常用推荐

| 配方 | 适合什么 | 采用条件 |
|---|---|---|
| 几何半调印刷 | 工业、技术、编辑传播主视觉 | 主体与主张相容时优先，文字区减弱网点 |
| 现代木刻套色 | 文化、叙事、明确轮廓的主题 | 内容相容时优先，精密说明不套刻纹 |
| 编辑摄影 | 产品身份、具体人物与应用场景 | 原始证据保持身份，生成场景作为示意 |
| 纯净几何色面 | 现代活动与主题图形 | 形体帮助识别主题，布局由方法确定 |
| 高对比重字形 | 短而明确的文字主张 | 中文关键字完整，不为效果压扁正文 |
| 精致衬线编辑 | 品质、文化、出版和叙事 | 字图主次清楚，实际字体和观看距离可读 |

摄影拼贴、孔版、剪纸、笔墨、水彩、光学条纹等按题材参与；它们不自动进入科研正文。主视觉先服务主张与身份，不能因喜欢某种纹理就强行采用。

## 保持库的边界清楚

- 版式、网格、Bento、等距、泳道、多面板和阅读次序归方法；色彩、线条、造型、光影、材质与字体气质归风格。
- 图标、背景、装饰与组件归[共享素材](shared-materials.md)，素材多不要求每个节点加图标。真实截图、照片和数值图按原始身份处理。
- 风格名帮助理解，模块推荐帮助定位；不为凑数重复登记明暗版、配色或同一种制版效果。
