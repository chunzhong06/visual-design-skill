# 简约设计 / Minimal Design

类别：工作传播视觉语言。别名：简约设计、Minimal Design、极简、极简风、极简主义、Minimalism、Minimalist Design。

## 理解与适用

工作设计里通常指减少非必要元素与装饰；艺术运动Minimalism有自己的历史和材料语境。

必要特征：保留足以表达核心信息的元素、层级与可读性。

适合大多数工作配图；复杂内容以分层展开实现简洁，不能减掉关键连接。

## 方法建议

取舍、留白和信息层级交模块；不得用简约为由删除必要流程、数值或限定条件。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 少量有功能的颜色，不限黑白 |
| 线条 | 清楚、克制，按对象选择 |
| 造型 | 简明而保留识别特征 |
| 光影 | 平涂或自然柔光 |
| 材质 | 低纹理；可有必要真实材质 |
| 字体气质 | 易读且层级明确，不一律细字 |

## 配方与自主设计

可借参数：[中性无衬线编辑](../styles/neutral-sans.md)、[棚拍产品质感](../styles/studio-product.md)、[精致衬线编辑](../styles/serif-editorial.md)、[哑光立体](../styles/soft-3d.md)。这些是候选，不是一对一绑定。

可直接自主设计；用户谈艺术运动时按该语境解释，不把所有简约工作图称为历史作品。

不由名称推断：不默认黑白、极细灰字、巨大空白或删减事实。
