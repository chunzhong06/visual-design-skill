# 孔版套色 / Risograph

类别：编辑与印刷称呼。别名：孔版套色、Risograph、Riso、Riso Print、孔版印刷、Risograph印刷。

## 理解与适用

以少色、半透明叠印、颗粒与轻套印差异表达印刷触感；不同于木刻刀痕。

必要特征：颜色叠压与制版颗粒有秩序，关键边缘和文字清楚。

适合活动、文化、教育海报与章节配图；专业流程标签区减纹理。

## 方法建议

模块决定图文和阅读层级，印刷表现不固定上下双联或对象。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 少量专色与叠印综合色 |
| 线条 | 颗粒边缘和受控制版点 |
| 造型 | 概括块面保留主题轮廓 |
| 光影 | 靠墨色与叠印建立明暗 |
| 材质 | 纸纤维、吸墨和轻错印 |
| 字体气质 | 清楚展示字，正文承载区克制 |
