# 双色编辑视觉 / Duotone Editorial

类别：编辑与印刷称呼。别名：双色编辑视觉、Duotone Editorial、Duotone、双色调、双色印刷风。

## 理解与适用

以两种主色转译影像与图形，形成鲜明而统一的色调；Bento等分区不是它的必需特征。

必要特征：两色明暗关系清楚，重要对象和文字保留反差。

适合产品与活动海报、封面和章节；证据原件保持原貌，转译图按示意使用。

## 方法建议

模块负责图片角色、分区与留白；状态数量超过两类时另保持准确颜色或文字编码。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 两种有分工的主色，不固定蓝橙 |
| 线条 | 保留摄影边缘或清楚轮廓 |
| 造型 | 主题对象保留比例与身份 |
| 光影 | 双色调阶承载明暗 |
| 材质 | 平滑数字或轻印刷触感 |
| 字体气质 | 清楚现代字形，字色与底色反差稳定 |

## 配方与自主设计

可借参数：[双色摄影转译](../styles/duotone-photo.md)、[简洁平面插画](../styles/clean-flat.md)。这些是候选，不是一对一绑定。

可自主转译纯图形；不必同时加入粗野边框、阴影或网点。

不由名称推断：不自动加入Bento、条码、假表格或把不同数据状态并为同一色。
