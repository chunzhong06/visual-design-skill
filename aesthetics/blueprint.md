# 工程蓝图语言 / Blueprint

类别：技术演示视觉语言。别名：工程蓝图语言、Blueprint、蓝图风、工程蓝图、技术制图风。

## 理解与适用

工作设计里常指精密技术线与低干扰底色；投影、结构与尺寸信息需另有真实依据。

必要特征：线条清楚、对象关系准确、装饰与真实连接可区分。

适合机制、架构、设备说明与技术海报；背景网格不能盖过正文。

## 方法建议

投影、剖视、节点和流向由模块按材料确定；不因名称自行加三视图、尺码或结构。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 蓝底浅线或浅底深线均可，语义色稳定 |
| 线条 | 有主次的精密细线 |
| 造型 | 保留真实结构与必要几何概括 |
| 光影 | 以轮廓和少量明暗解释体块 |
| 材质 | 低纹理底色，网格可选且低干扰 |
| 字体气质 | 标签清楚，必要数值与符号准确 |

## 配方与自主设计

可借参数：[精密线描](../styles/technical-line.md)、[简洁平面插画](../styles/clean-flat.md)。这些是候选，不是一对一绑定。

可自主形成浅色精密图解；不需要假坐标、刻度和条码来显得专业。

不由名称推断：不添加未经材料支持的尺寸、数学公式、端口、机械零件或数据。
