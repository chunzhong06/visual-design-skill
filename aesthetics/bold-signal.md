# 高反差明确信号 / Bold Signal

类别：工作传播视觉语言。别名：高反差明确信号、Bold Signal、高反差品牌平面、Bold Signal Style、信号式平面。

## 理解与适用

以高反差、少量强色和有力量的字形建立明确焦点，是发布与专业演示的工作预设。

必要特征：主张清楚，强色有目的，视觉不依赖材料炫技。

适合项目发布、主张型海报与封面；内容页降低强色面积。

## 方法建议

主张、字图比例和焦点交模块；可以文字或真实产品主导，不要求卡片阵列。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 黑白或深浅强反差，少量鲜明强调色 |
| 线条 | 硬边与明确分隔 |
| 造型 | 简明几何或经过提炼的真实对象 |
| 光影 | 平涂为主，必要光影克制 |
| 材质 | 干净图形表面，可按内容选局部影像 |
| 字体气质 | 粗重有力量的字形，正文层级清楚 |

## 配方与自主设计

可借参数：[高对比重字形](../styles/bold-type.md)、[纯净几何色面](../styles/geometric-flat.md)、[纯净几何色面](../styles/geometric-flat.md)。这些是候选，不是一对一绑定。

可自主形成文字或产品视觉，不为名称插入巨大数字或发光背景。

不由名称推断：不添加虚构业绩、夸张口号、营销价格或无关统计。
