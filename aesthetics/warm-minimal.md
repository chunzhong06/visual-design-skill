# 暖调简约 / Warm Minimal

类别：工作传播视觉语言。别名：暖调简约、Warm Minimal、暖色极简、温暖简约、Warm Minimalism。

## 理解与适用

以暖中性色、克制边缘和适量柔和材料建立平静亲和感；是工作预设而非独立历史流派。

必要特征：温和氛围与稳定识读共存，必要信息不因柔和而消失。

适合培训、教育、服务和工作汇报；背景与装饰保持安静。

## 方法建议

模块决定留白与密度，亲和不要求每个对象圆角卡片化。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 暖白、米或石色配受控强调色 |
| 线条 | 清楚软硬边对照 |
| 造型 | 概括而有识别度，可少量自然形 |
| 光影 | 柔光或平涂，阴影适度 |
| 材质 | 干净平面、哑光或少量纸面 |
| 字体气质 | 易读无衬线或克制衬线，正文反差清楚 |

## 配方与自主设计

可借参数：[精致衬线编辑](../styles/serif-editorial.md)、[棚拍产品质感](../styles/studio-product.md)、[哑光立体](../styles/soft-3d.md)、[柔光渐变](../styles/atmospheric-light.md)。这些是候选，不是一对一绑定。

按对象选择媒介，不把所有候选同时叠加；不要求低饱和到底。

不由名称推断：不自动加入儿童、植物、奶油玩具或极浅小字。
