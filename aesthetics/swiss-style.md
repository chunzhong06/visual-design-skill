# 瑞士国际主义 / International Typographic Style

类别：平面设计传统。别名：瑞士国际主义、International Typographic Style、瑞士风格、瑞士平面、Swiss Style、Swiss Typography、国际主义平面风格、瑞士现代、Swiss Modern。

## 理解与适用

以清晰、结构和字体关系见长的平面设计语言；不局限黑白或纯文字。

必要特征：内容层级、对齐关系与易读字体相互支持。

适合内容海报和工作PPT；密集图保留层级与连续阅读，不将所有元素等大。

## 方法建议

网格、字图比例与对齐建议交模块，尊重当前模板；规则网格可承载不对称视觉平衡。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 克制色盘，少量信号色 |
| 线条 | 准确细线或清楚块边 |
| 造型 | 清楚几何及直接摄影 |
| 光影 | 平整或自然摄影光 |
| 材质 | 低装饰表面，不强加旧纸 |
| 字体气质 | 中性无衬线，中文采用协调且易读字形 |

## 配方与自主设计

可借参数：[中性无衬线编辑](../styles/neutral-sans.md)、[纯净几何色面](../styles/geometric-flat.md)、[编辑摄影](../styles/editorial-photo.md)。这些是候选，不是一对一绑定。

字图与留白质量依赖模块；仅应用卡片的媒介纹理无法完成此名称要求。

不由名称推断：不强制Helvetica品牌字库、黑白、九宫格或单一历史海报复刻。
