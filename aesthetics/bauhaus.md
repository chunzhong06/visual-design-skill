# 包豪斯 / Bauhaus

类别：平面设计传统。别名：包豪斯、Bauhaus、包豪斯风、包豪斯风格。

## 理解与适用

现代设计传统，既涉及形态与色彩，也涉及字图秩序、材料与功能；几何半调只是可组合的处理。

必要特征：提取清楚的几何关系、字图联系与功能性；允许纯净平面、摄影或有选择的印刷质感。

海报可强化形体与标题呼应；PPT用共同几何、颜色和字体，背景降低图形数量，解释图区保持关系。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 有限色盘与明确反差；可用原色，也可按品牌调整 |
| 线条 | 清楚硬边与少量结构线 |
| 造型 | 基本几何与主题对象建立联系 |
| 光影 | 平涂或受控的摄影明暗 |
| 材质 | 干净平面为可用起点；纸纹、网点、磨损均可选 |
| 字体气质 | 几何或中性无衬线；字体大小和位置交模块 |

## 配方与自主设计

可借参数：[纯净几何色面](../styles/geometric-flat.md)、[中性无衬线编辑](../styles/neutral-sans.md)、[编辑摄影](../styles/editorial-photo.md)、[几何半调印刷](../styles/geometric-print.md)。这些是候选，不是一对一绑定。

没有印刷要求时自主采用纯净几何，不必读取半调卡；有无纸纹约束时显式关闭纸纹。

不由名称推断：不自动加入红黄蓝、圆方三角全套、德文、历史年份、网点旧纸或特定人物。
