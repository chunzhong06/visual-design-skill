# 当代编辑视觉 / Contemporary Editorial

类别：工作传播视觉语言。别名：当代编辑视觉、Contemporary Editorial、编辑视觉、编辑设计风、Editorial Design、杂志气质。

## 理解与适用

以有目的的字体、图像与反差形成当代编辑气质；“杂志感”同时可能包含组织要求，需分开处理。

必要特征：图像和文字支持同一主张，字体与图像风格协调。

适合项目传播、研究故事和产品海报；PPT保留标题层级与图像品质，正文保持可编辑。

## 方法建议

标题、栏位、图注和阅读顺序交模块；不强制六格、划线字或特定期刊模板。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 克制底色与清楚强调色，按题材选冷暖 |
| 线条 | 图像边缘与少量精确分隔线 |
| 造型 | 写实或图形化均可，主体有辨识度 |
| 光影 | 自然摄影或平面明暗 |
| 材质 | 干净数字或适量纸面，不强制复古 |
| 字体气质 | 有辨识度的展示字搭配清楚正文，衬线与无衬线按语境选择 |

## 配方与自主设计

可借参数：[中性无衬线编辑](../styles/neutral-sans.md)、[精致衬线编辑](../styles/serif-editorial.md)、[编辑摄影](../styles/editorial-photo.md)、[摄影纸本拼贴](../styles/editorial-collage.md)。这些是候选，不是一对一绑定。

可纯文字主导或真实产品图主导，不需要把所有元素拼贴化。

不由名称推断：不自动加入报纸日期、假引用、装饰小字、虚构采访或无关人物。
