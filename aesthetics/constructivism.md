# 构成主义 / Constructivism

类别：平面设计传统。别名：构成主义、Constructivism、构成主义风格、构成派。

## 理解与适用

重视构造与抽象的艺术传统；工作海报可转译成有方向的块面与结构关系。

必要特征：让形体组织表达主题的力量与方向，不只套一组红黑斜线。

海报可有强张力；PPT背景减弱对角冲击，内容图保留实际流向。

## 方法建议

模块可用方向性字图关系和非对称平衡；真实因果、时间顺序与连接不随斜线装饰改变。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 可用高反差少色，红黑仅为一种选项 |
| 线条 | 硬边、直线与明确方向 |
| 造型 | 几何块体与概括对象 |
| 光影 | 平面明暗或工业摄影 |
| 材质 | 纯色、摄影或受控印刷 |
| 字体气质 | 有力量的无衬线，关键信息清楚 |

## 配方与自主设计

可借参数：[高对比重字形](../styles/bold-type.md)、[纯净几何色面](../styles/geometric-flat.md)、[摄影纸本拼贴](../styles/editorial-collage.md)。这些是候选，不是一对一绑定。

方向性由内容和组织决定，按需自主构造；不继承来源政治口号。

不由名称推断：不自动加入政治符号、宣传口号、红星或历史人物。
