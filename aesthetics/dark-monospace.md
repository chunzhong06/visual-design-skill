# 深色等宽 / Dark Monospace

类别：技术演示视觉语言。别名：深色等宽、Dark Monospace、深色等宽风、暗色技术排版、等宽技术风。

## 理解与适用

专业技术演示中的深色基底与等宽字形气质；代码、终端和数据必须来自内容。

必要特征：深底高识读、清楚的字形节奏，信号色有克制分工。

适合开发者、基础设施和有真实技术材料的汇报；投影时保证标签反差。

## 方法建议

模块判断代码与技术标记是否必要；中文正文使用合适字形，不为等宽牺牲识读。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 近黑或深蓝底，高对比文字和少量信号色 |
| 线条 | 细而清楚的技术线 |
| 造型 | 简洁几何与真实技术对象 |
| 光影 | 平涂或低强度光影 |
| 材质 | 干净数字表面，不必CRT与扫描线 |
| 字体气质 | 等宽用于代码或短标记，中文正文保持清楚 |

## 配方与自主设计

可借参数：[精密线描](../styles/technical-line.md)、[简洁平面插画](../styles/clean-flat.md)、[柔光渐变](../styles/atmospheric-light.md)。这些是候选，不是一对一绑定。

按项目自主选择深色方案；安全项目不因为题材自动选黑客终端。

不由名称推断：不添加假代码、矩阵雨、凭据、扫描结果或无关命令窗口。
