# 新粗野主义平面 / Neobrutalism

类别：工作传播视觉语言。别名：新粗野主义平面、Neobrutalism、新粗野主义、Neo Brutalism、Neubrutalism。

## 理解与适用

以高反差、粗边框、鲜明色面和硬偏移阴影形成直接的平面视觉。

必要特征：轮廓、色块与硬阴影形成清楚层次，保留可用性。

适合强信息海报和重点页；PPT背景减少边框数量，关系图保持线条区分。

## 方法建议

模块按内容安排块体和标题；视觉强烈不要求故意打乱阅读。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 强反差，鲜明信号色配中性色 |
| 线条 | 粗硬边框，线宽有层级 |
| 造型 | 简明块面和清楚轮廓 |
| 光影 | 硬边偏移阴影，不用柔糊光晕 |
| 材质 | 平滑图形或少量原始印刷触感 |
| 字体气质 | 粗重直接的字形，正文清楚 |

## 配方与自主设计

可借参数：[硬边高对比图形](../styles/hard-edge-graphic.md)、[简洁平面插画](../styles/clean-flat.md)、[纯净几何色面](../styles/geometric-flat.md)、[双色摄影转译](../styles/duotone-photo.md)。这些是候选，不是一对一绑定。

自主补足硬阴影与边框即可；不必复制来源模板的分格布局。

不由名称推断：不自动加Bento、怪诞字、混凝土建筑或故意不可读排版。
