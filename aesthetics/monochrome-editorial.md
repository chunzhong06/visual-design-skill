# 单色编辑印刷 / Monochrome Editorial

类别：编辑与印刷称呼。别名：单色编辑印刷、Monochrome Editorial、单色editorial、单色印刷风、黑白编辑印刷。

## 理解与适用

将影像和图形统一到单墨或有限明暗阶，形成清楚、有触感的编辑视觉。

必要特征：主次靠明暗与形态成立，制版特征按用途控制。

适合宣传主视觉和章节页；PPT密集内容不满版颗粒化。

## 方法建议

主视觉与信息层级交模块，单色不删除必要状态区分。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 单一墨色与底色，少量强调色仅按任务需要 |
| 线条 | 摄影边缘或清楚图形边缘，可局部网点 |
| 造型 | 对象轮廓在减色后仍可辨 |
| 光影 | 用受控调阶或网点建立明暗 |
| 材质 | 纸面、吸墨和半调可选，干净版本也可 |
| 字体气质 | 有力量的编辑展示字配清楚正文 |

## 配方与自主设计

可借参数：[几何半调印刷](../styles/geometric-print.md)、[双色摄影转译](../styles/duotone-photo.md)、[编辑摄影](../styles/editorial-photo.md)。这些是候选，不是一对一绑定。

单色不是必须做旧；原材料有多状态时保留形状、文字或额外语义编码。

不由名称推断：不自动添加胶带、污渍、旧日期或巨型无关英文。
