# 企业现代主义 / Corporate Modernism

类别：工作传播视觉语言。别名：企业现代主义、Corporate Modernism、企业现代主义风格、Mid-Century Corporate、IBM heritage look。

## 理解与适用

用稳定的几何、清楚字形和成套图形语法建立专业身份；此条是工作语言解释，不要求复制某家企业。

必要特征：图形、字形、色彩形成一致且可延展的系统，能够承载产品与证据。

适合产品海报、企业与项目汇报；封面加强身份，解释页减少装饰，证据页尊重真实截图。

## 方法建议

模块按内容安排字图、留白和层级；品牌识别不靠一张流程图或一套标志重复。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 克制底色与少量有语义的强调色 |
| 线条 | 规整边缘、清楚主次 |
| 造型 | 几何提炼、产品对象保留身份 |
| 光影 | 平涂或受控自然光 |
| 材质 | 干净平面为主，印刷可选 |
| 字体气质 | 清楚有力量的无衬线，必要正文易读 |

## 配方与自主设计

可借参数：[中性无衬线编辑](../styles/neutral-sans.md)、[纯净几何色面](../styles/geometric-flat.md)、[棚拍产品质感](../styles/studio-product.md)、[精密线描](../styles/technical-line.md)。这些是候选，不是一对一绑定。

可自主形成新图形系统；只借相关卡的部分参数，不把IBM蓝或条纹当成必需。

不由名称推断：不自动加入IBM标志、八道条纹、公司口号、虚构产品界面或成绩。
