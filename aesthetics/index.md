# 工作美学名称索引

20个名称帮助解释日常设计要求；25张配方提供媒介参数。名称可跨配方，也可自主设计。先按[名称规则](../references/aesthetic-interpretation.md)判断请求中的作用，再只读相关卡。

这里既有平面设计传统，也有公开项目中的工作预设。不同性质分别标注，按照海报/PPT的内容、受众与实际用法选择。名称不作为主题匹配或默认风格的理由。

可选离线定位：`python scripts/resolve_aesthetic.py --query "瑞士现代，但不要纸纹"`；它仅定位提及，由Codex解释肯定、否定和局部参考。

## 平面设计传统

| 名称 | 解释范围 |
|---|---|
| [包豪斯 / Bauhaus](bauhaus.md) | 现代设计传统，既涉及形态与色彩，也涉及字图秩序、材料与功能；几何半调只是可组合的处理。 |
| [瑞士国际主义 / International Typographic Style](swiss-style.md) | 以清晰、结构和字体关系见长的平面设计语言；不局限黑白或纯文字。 |
| [构成主义 / Constructivism](constructivism.md) | 重视构造与抽象的艺术传统；工作海报可转译成有方向的块面与结构关系。 |
| [风格派 / De Stijl](de-stijl.md) | 几何抽象与色面关系的设计传统；常见横竖构造，但运动内部并非只有一种规则。 |
| [装饰艺术 / Art Deco](art-deco.md) | 融合几何、工艺与多种装饰来源的设计语言，黑金不是其唯一表现。 |
| [新艺术 / Art Nouveau](art-nouveau.md) | 强调流动线、自然形态与结构装饰结合的传统，也有几何化变体。 |
| [孟菲斯 / Memphis Design](memphis.md) | 带有鲜明色块、几何图案与材料混搭的后现代设计语言。 |
| [波普艺术 / Pop Art](pop-art.md) | 借用流行与商业文化的艺术语言；漫画网点、重复与广告式色块都是可选路径。 |

## 工作传播视觉语言

| 名称 | 解释范围 |
|---|---|
| [简约设计 / Minimal Design](minimal-design.md) | 工作设计里通常指减少非必要元素与装饰；艺术运动Minimalism有自己的历史和材料语境。 |
| [扁平设计 / Flat Design](flat-design.md) | 以清楚色面与形状表达对象，减弱装饰性仿真体积。 |
| [新粗野主义平面 / Neobrutalism](neobrutalism.md) | 以高反差、粗边框、鲜明色面和硬偏移阴影形成直接的平面视觉。 |
| [企业现代主义 / Corporate Modernism](corporate-modernism.md) | 用稳定的几何、清楚字形和成套图形语法建立专业身份；此条是工作语言解释，不要求复制某家企业。 |
| [当代编辑视觉 / Contemporary Editorial](contemporary-editorial.md) | 以有目的的字体、图像与反差形成当代编辑气质；“杂志感”同时可能包含组织要求，需分开处理。 |
| [暖调简约 / Warm Minimal](warm-minimal.md) | 以暖中性色、克制边缘和适量柔和材料建立平静亲和感；是工作预设而非独立历史流派。 |
| [高反差明确信号 / Bold Signal](bold-signal.md) | 以高反差、少量强色和有力量的字形建立明确焦点，是发布与专业演示的工作预设。 |

## 编辑与印刷称呼

| 名称 | 解释范围 |
|---|---|
| [单色编辑印刷 / Monochrome Editorial](monochrome-editorial.md) | 将影像和图形统一到单墨或有限明暗阶，形成清楚、有触感的编辑视觉。 |
| [双色编辑视觉 / Duotone Editorial](duotone-editorial.md) | 以两种主色转译影像与图形，形成鲜明而统一的色调；Bento等分区不是它的必需特征。 |
| [孔版套色 / Risograph](risograph.md) | 以少色、半透明叠印、颗粒与轻套印差异表达印刷触感；不同于木刻刀痕。 |

## 技术演示视觉语言

| 名称 | 解释范围 |
|---|---|
| [工程蓝图语言 / Blueprint](blueprint.md) | 工作设计里常指精密技术线与低干扰底色；投影、结构与尺寸信息需另有真实依据。 |
| [深色等宽 / Dark Monospace](dark-monospace.md) | 专业技术演示中的深色基底与等宽字形气质；代码、终端和数据必须来自内容。 |
