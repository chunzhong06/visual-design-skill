# 孟菲斯 / Memphis Design

类别：平面设计传统。别名：孟菲斯、Memphis Design、Memphis、孟菲斯风格。

## 理解与适用

带有鲜明色块、几何图案与材料混搭的后现代设计语言。

必要特征：轻松、鲜明的图形节奏；控制图案数量和主次。

适合活动和创意海报；PPT封面可活泼，背景与流程使用少图案版本。

## 方法建议

模块决定散点、重复和动势，不能让装饰取代阅读路径。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 鲜明撞色或受控粉彩，可按品牌减色 |
| 线条 | 粗轮廓、短线、波浪和点状图案 |
| 造型 | 几何与不规则形并置 |
| 光影 | 平涂或少量硬边体积 |
| 材质 | 平滑图形或可选塑料层压触感 |
| 字体气质 | 活泼展示字配清楚正文 |

## 配方与自主设计

可借参数：[简洁平面插画](../styles/clean-flat.md)、[马克笔涂鸦](../styles/marker-doodle.md)、[哑光立体](../styles/soft-3d.md)。这些是候选，不是一对一绑定。

材料不是必选；自主用少量图形即可传达，避免所有图案同时出现。

不由名称推断：不自动添加家具、豹纹、玩具或艳色全套。
