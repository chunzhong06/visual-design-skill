# 风格派 / De Stijl

类别：平面设计传统。别名：风格派、De Stijl、新造型主义、Neo-Plasticism、Neoplasticism、蒙德里安式。

## 理解与适用

几何抽象与色面关系的设计传统；常见横竖构造，但运动内部并非只有一种规则。

必要特征：少量线与色面建立明确比例和秩序。

适合图形海报、章节背景与分区装饰；正文区保留大块安静底色。

## 方法建议

模块按内容确定分区与留白，装饰性格线不冒充数据表或实际流程。

## 六维参数起点

| 维度 | 参数 |
|---|---|
| 色彩 | 原色与黑白可作起点，按明确品牌约束转译 |
| 线条 | 规整直线与清楚边界 |
| 造型 | 矩形块面；需要斜线时说明所取语言 |
| 光影 | 平涂、无体积为主 |
| 材质 | 平滑色面，不需要纸纹 |
| 字体气质 | 中性几何无衬线 |

## 配方与自主设计

可借参数：[纯净几何色面](../styles/geometric-flat.md)。这些是候选，不是一对一绑定。

独立调整比例和色面即可，不把一张名画的构图直接移植为模板。

不由名称推断：不自动复制名画、签名或固定三色数值。
