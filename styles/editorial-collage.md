# 摄影纸本拼贴

标识：`editorial-collage`；组别：纸本与材料拼贴。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 照片综合色调与纸色协调，可用有限图形强调色 |
| 线条 | 摄影切边与撕裂纸边形成可辨差别 |
| 造型 | 照片碎片与平面形体混合，主体识别清楚 |
| 光影 | 保留局部摄影明暗，以接触阴影说明层叠 |
| 材质 | 纸缝、折痕、扫描印刷触感与摄影纹理 |
| 字体气质 | 清楚编辑字形，正文不依靠碎片化字形 |

可选变体：可按参考保留碎片原光线；需要可信实景合成时另由模块要求统一光线。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：不同媒介有明确分工，不用随机碎片打断真实关系。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
