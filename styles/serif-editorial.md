# 精致衬线编辑

标识：`serif-editorial`；组别：字形与编辑表面。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 暖中性或深中性底，少量稳定强调色 |
| 线条 | 纤细规则与清楚图像边界 |
| 造型 | 比例舒展的对象与有识别度的摄影 |
| 光影 | 受控自然光或平面明暗 |
| 材质 | 清爽或轻纸面，避免默认复古污渍 |
| 字体气质 | 展示衬线配可读正文，中文宋体/衬线按实际字体选择 |

## 适配与强度

文化、研究故事、作品与品质表达；不强制金色、人物肖像和假引语。

使用条件：细衬线在小尺寸下容易丢失；密集解释区改清楚正文。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
