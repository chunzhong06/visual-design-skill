# 马克笔涂鸦

标识：`marker-doodle`；组别：线条与手绘。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 少量有分工的色彩，点色与主色区分 |
| 线条 | 松弛线条、马克笔粗细变化和自然露白 |
| 造型 | 简化轮廓、略不规则但语义清楚 |
| 光影 | 少量色块，不追求完整写实体积 |
| 材质 | 马克笔叠色与轻手工涂抹 |
| 字体气质 | 自然手写气质，准确文字保持清楚 |

## 适配与强度

可考虑的图片角色：海报主视觉、封面、概念解释、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：涂鸦符号须服务内容，不自动添笑脸、闪电或无意义标记。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
