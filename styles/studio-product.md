# 棚拍产品质感

标识：`studio-product`；组别：摄影与光学处理。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 材料本色与中性环境，强调色来自项目 |
| 线条 | 自然清楚的物体边缘与适度景深 |
| 造型 | 比例可信的完整对象及真实材质细节 |
| 光影 | 受控主光、柔和接触阴影，反射有来源 |
| 材质 | 可信的金属、塑料、织物等实物表面 |
| 字体气质 | 简洁展示字与清楚说明 |

## 适配与强度

产品、设备、成果对象与独立素材；不强制居中、巨字遮挡或商品广告口号。

使用条件：只画有依据的产品身份；软件界面保留真实截图，不虚构实体硬件。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
