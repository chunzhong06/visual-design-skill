# 精密实体渲染

标识：`precision-3d`；组别：立体与表面材质。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 克制底色，材料色与有语义的强调色 |
| 线条 | 由准确实体边缘和局部轮廓线形成层次 |
| 造型 | 比例明确、体块可靠；投影与展开关系交模块 |
| 光影 | 可解释的主光与接触阴影，控制高光 |
| 材质 | 磨砂塑料、金属或陶瓷等按内容选择，不一律黏土 |
| 字体气质 | 清楚现代标签，必要文字由原生排版承载 |

## 适配与强度

真实结构、设备和对象解释，适度空间感；与柔和圆润的哑光立体区分。

使用条件：内部构造、接口和剖面须有来源；不能让真实设备或系统变成虚构零件。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
