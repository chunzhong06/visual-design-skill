# 中性无衬线编辑

标识：`neutral-sans`；组别：字形与编辑表面。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 中性浅底或深底，少量有语义的强调色 |
| 线条 | 准确细线与规整边缘，线重有主次 |
| 造型 | 清楚的平面对象或保持身份的真实图像 |
| 光影 | 平整、低反射，必要体积从简 |
| 材质 | 干净数字表面，无默认噪点和纸纹 |
| 字体气质 | 中性无衬线，中英字重与视觉体量协调 |

## 适配与强度

技术、产品、项目汇报；图片细节随角色变化，不把正文印成图。

使用条件：避免所有对象等重、无焦点或默认卡片化；低装饰仍需内容主张。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
