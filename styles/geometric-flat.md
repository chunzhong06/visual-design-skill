# 纯净几何色面

标识：`geometric-flat`；组别：平面造型。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 明确分工的有限色，底色可冷可暖 |
| 线条 | 干净硬边，按需少量精确描边 |
| 造型 | 圆、矩形和有机概括形按主题组合 |
| 光影 | 平涂为主，不依赖渐变和体积 |
| 材质 | 低纹理实色，套印为可选局部处理 |
| 字体气质 | 几何或中性字形，中文保持清楚比例 |

## 适配与强度

现代主义、文化活动及解释图；不限红黄蓝，也不固定三角圆形组合。少色硬边剪影可作为对象概括的局部变体，保持主体识别与必要关系，不另计一张风格卡。

使用条件：几何必须支持主题；装饰形状不冒充真实流程和数据。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
