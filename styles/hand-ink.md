# 手绘钢笔线稿

标识：`hand-ink`；组别：线条与手绘。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 黑白或少量低饱和设色，纸色按用途选择 |
| 线条 | 自然轻抖动、提按与少量排线 |
| 造型 | 手绘概括而保留主体特征 |
| 光影 | 少量排线或淡色提示明暗 |
| 材质 | 纸面和墨线触感，避免机械均匀矢量边 |
| 字体气质 | 克制手写或清楚的中性字形 |

可选变体：可选生活速写或复古装饰细线；满版纹样属于模块组织方式。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、概念解释、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：结构图需要精确连接时减少抖线，重要标注交排版。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
