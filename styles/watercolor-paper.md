# 透明水彩

标识：`watercolor-paper`；组别：笔墨与颜料。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 透明协调色盘，保留纸白，按内容控制综合色温 |
| 线条 | 软硬水边、少量清楚轮廓 |
| 造型 | 提炼形体，主要对象比次要环境清楚 |
| 光影 | 透明叠色、淡化和纸白形成轻明暗 |
| 材质 | 水渍边、颗粒、干湿变化与水彩纸 |
| 字体气质 | 清楚的编辑字或克制手写气质 |

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。
