# 双色摄影转译

标识：`duotone-photo`；组别：摄影与光学处理。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 两种有分工的主色，明暗阶对应两色混合 |
| 线条 | 摄影边缘保留，边界不另加刻线 |
| 造型 | 摄影主体结构与比例可辨 |
| 光影 | 将摄影明暗压入双色调阶 |
| 材质 | 平整或轻纸面印刷触感，网点不是必选 |
| 字体气质 | 清楚的几何或中性字形 |

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、独立素材。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：不能用两种颜色混淆原有多个状态；不强制Bento分区。
