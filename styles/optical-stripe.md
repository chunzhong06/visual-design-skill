# 光学条纹图形

标识：`optical-stripe`；组别：平面造型。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 高反差黑白或有限双色，可局部一色强调 |
| 线条 | 有规律的平行、弯曲与疏密节奏 |
| 造型 | 平面带状与负形，按主题概括 |
| 光影 | 以图形反差为主，不假装真实物体光照 |
| 材质 | 干净平面，轻纸面可选，不必做旧 |
| 字体气质 | 清楚展示字与稳定正文，不强制高反差衬线 |

## 适配与强度

活动、艺术、运动等主题适合时使用；布局和方向交模块，不自动生成旋涡或数据波形。

使用条件：避免细密摩尔纹和眩晕；条纹不穿越小字、图例和证据区。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
