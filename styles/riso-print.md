# 少色孔版印刷

标识：`riso-print`；组别：制版与印刷。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 少量专色，半透明叠印产生综合色，不固定橙绿 |
| 线条 | 颗粒边缘、点描或粗网点 |
| 造型 | 概括块面，不预设可爱人物或夸张道具 |
| 光影 | 网点密度和色版叠压形成明暗 |
| 材质 | 不均匀印墨、轻套印错位与纸纤维 |
| 字体气质 | 清楚且与制版触感协调的字形 |

可选变体：核心是分色叠印；主题、画幅、视角和几何构图由模块处理。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：细密文字保持干净承载区，不用随机噪点代替印版结构。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
