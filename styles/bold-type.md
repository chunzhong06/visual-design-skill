# 高对比重字形

标识：`bold-type`；组别：字形与编辑表面。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 强明暗与少量信号色，按内容决定冷暖 |
| 线条 | 利落字边与少量硬边图形 |
| 造型 | 饱满字形配直接、易辨的主题对象 |
| 光影 | 平面反差为主，摄影光向保持统一 |
| 材质 | 干净数字或极轻印刷，不强加颗粒 |
| 字体气质 | 粗重无衬线或有力展示字，保持文字完整 |

## 适配与强度

活动、项目主张与章节强调；字图位置、断行和遮挡归模块。

使用条件：完整关键字优先；中文不机械压窄，正文不用极端字形。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
