# 硬边高对比图形

标识：`hard-edge-graphic`；组别：平面造型。

## 视觉参数

| 维度 | 可复用特征 |
|---|---|
| 色彩 | 稳定浅/深底配一至少量高反差强调，按内容决定冷暖与饱和度 |
| 线条 | 清楚硬轮廓，粗细有层级，不给所有物体同样粗边 |
| 造型 | 直接、可辨的平面对象与明确色块；版式由模块决定 |
| 光影 | 少量方向一致的实色硬阴影，可完全关闭，不用模糊浮雕 |
| 材质 | 干净数字色面，印刷肌理仅为局部可选 |
| 字体气质 | 有力度且完整可读的展示字配清楚正文，中文不机械压窄 |

适合需要明确态度的海报、PPT封面、章节或少量概念比较；正式解释区降低边框和阴影强度。密集论文方法图不将它作为默认表面语言。不能因“新粗野”自动加入号码、贴纸、卡片网格、霓虹或随意倾斜。

## 来源与独立转译

- [PPTX Design Styles的Neo-Brutalism](https://github.com/corazzon/pptx-design-styles/blob/main/references/styles.md)：提炼硬边与硬阴影，不沿用固定字号、全元素粗边和强制布局。
- [Fantastic Posters的brutalist-broadcast](https://github.com/robonuggets/fantastic-posters/blob/main/styles.js)：提炼色面与展示字力度，不沿用原主题、信息、三行布局或完整提示词。
