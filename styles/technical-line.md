# 精密线描

标识：`technical-line`；组别：线条与手绘。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 少色且颜色含义稳定，底色依项目决定 |
| 线条 | 均匀细线配合清楚的主次线宽 |
| 造型 | 形体简化而准确，不强制投影 |
| 光影 | 以轮廓与少量明暗说明体块 |
| 材质 | 低纹理干净表面，蓝底仅为可选处理 |
| 字体气质 | 中性清楚、适合标签与小字号 |

可选变体：深底浅线和浅底深线均可，不等于必须采用等距或三视图。
