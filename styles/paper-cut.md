# 和纸与剪纸层叠

标识：`paper-cut`；组别：纸本与材料拼贴。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 有限纸色，可按内容冷暖调整 |
| 线条 | 手工切边、撕边或胶带接边 |
| 造型 | 平面纸片或有厚度的纸形保留识别轮廓 |
| 光影 | 轻微层叠和接触阴影 |
| 材质 | 纸纤维、半透明和纸或胶带叠色 |
| 字体气质 | 清楚的编辑字形或纸本协调用字 |

可选变体：胶带、剪纸和纸模型的表面可分选；视角、层数与等距投影由模块决定。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、概念解释、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：纤维和叠层不要遮住关键轮廓与标签。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
