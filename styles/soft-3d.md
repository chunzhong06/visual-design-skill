# 哑光立体

标识：`soft-3d`；组别：立体与表面材质。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 有限色盘，柔和但保持对象反差 |
| 线条 | 由实体边缘形成轮廓 |
| 造型 | 简洁实体，圆角与体量随对象调整 |
| 光影 | 柔光、接触阴影与适度体积 |
| 材质 | 哑光、磨砂或黏土式表面 |
| 字体气质 | 清楚的现代字形，正文通常交最终排版 |
