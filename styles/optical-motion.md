# 光学动感摄影

标识：`optical-motion`；组别：摄影与光学处理。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 按场景选择连贯综合色，保留真实材料色 |
| 线条 | 主对象清楚，次要环境呈方向性光学柔化 |
| 造型 | 真实比例，主题对象保持可识别轮廓 |
| 光影 | 可信光线与受控光迹，不以泛光抹去主体 |
| 材质 | 真实材料加光学运动模糊，不用均匀磨皮 |
| 字体气质 | 清楚的几何或紧凑展示字 |

可选变体：清楚对象与模糊环境的分工由模块确定，不强制运动器材、特定视角或巨字。
