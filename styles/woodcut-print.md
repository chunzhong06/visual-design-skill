# 现代木刻套色

标识：`woodcut-print`；组别：制版与印刷。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 有限且有分工的套色，纸色和强调色按主题决定 |
| 线条 | 主轮廓与方向性刀口刻线 |
| 造型 | 提炼轮廓和块面，保留必要识别特征 |
| 光影 | 刻线密度、纸白与色版叠压形成明暗 |
| 材质 | 刀痕、吸墨边与轻微套印错位 |
| 字体气质 | 与版画协调的清楚展示字或正文用字 |

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：细密流程、连续小字和精密数值优先保持干净承载区。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
