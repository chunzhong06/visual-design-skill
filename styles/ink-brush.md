# 东方笔墨与书法

标识：`ink-brush`；组别：笔墨与颜料。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 墨色浓淡与纸白为主，设色按主题少量加入 |
| 线条 | 提按、枯湿、飞白与有方向的笔势 |
| 造型 | 形体提炼，轮廓可虚实相生但保留主体 |
| 光影 | 浓淡、留白与渗化表达层次 |
| 材质 | 宣纸吸墨、干湿变化与自然渗边 |
| 字体气质 | 需要时采用准确书法字形；小字采用清楚排版 |

可选变体：黑底鲜色书法和浅纸水墨分开选择，不同时强加；文字位置与笔势构成由模块决定。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、独立素材、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：书法字逐字核对，正文与科学符号不依赖难辨笔势。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
