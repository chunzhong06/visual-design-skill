# 清透折射材质

标识：`translucent-optics`；组别：立体与表面材质。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 透明中性色配少量清楚色光，不默认彩虹铺满 |
| 线条 | 清楚轮廓与有限折射边缘 |
| 造型 | 可辨完整对象，透明不抹掉主题 |
| 光影 | 受控透光、反射和局部焦散，高光不过曝 |
| 材质 | 透明树脂、磨砂玻璃等选一种主材质 |
| 字体气质 | 清楚字形置于稳定承载区，无字素材不加标记 |

## 适配与强度

材料主题、独立对象或低干扰局部装饰；不强制全页玻璃卡片与虚构未来设备。

使用条件：折射不扭曲准确文字、图表或真实界面；保持底色反差。

构图、字号、位置、投影、阅读顺序和连接归方法模块。封面、正文背景与解释对象可以用不同强度；无字素材不添加文字。当前明确参考与品牌优先，按[共享路由](../references/style-router.md)选择。
