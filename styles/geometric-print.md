# 几何半调印刷

标识：`geometric-print`；组别：制版与印刷。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 中性纸色或灰黑基底，有限强调色，冷暖按主题调整 |
| 线条 | 硬边轮廓与摄影网点并存，可有克制断墨 |
| 造型 | 主体保留识别特征，图形概括为明确块面 |
| 光影 | 制版式明暗，与平面色块统一 |
| 材质 | 可见网点、纸纤维、吸墨与少量套印偏差 |
| 字体气质 | 粗重或紧凑的几何无衬线，按所需文字调整 |

可选变体：单色制版、双色强调与局部漫画式网点按题材选择；它们是制版参数，不另计画风。现代印刷可使用干净纸面，网点不自动意味着复古污渍。巨字、裁切和穿插由模块决定；气泡、爆炸框和人物表情只由真实内容需要引入。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、场景、装饰。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：密集标签所在区域减弱网点和磨损，避免关键轮廓被噪声淹没。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
