# 简洁平面插画

标识：`clean-flat`；组别：平面造型。

## 视觉参数

| 维度 | 可复用视觉特征 |
|---|---|
| 色彩 | 有限且语义明确的色盘，冷暖按内容决定 |
| 线条 | 干净稳定的边缘，无描边或统一描边 |
| 造型 | 概括形体并保留识别特征 |
| 光影 | 平涂为主，少量简洁阴影 |
| 材质 | 低纹理色面；复古变体可轻量引入印刷颗粒 |
| 字体气质 | 清楚的中性或几何字形 |

可选变体：干净平涂与复古少色平涂分别选择，不默认合并纸纹和复古字体。

## 适配与强度

可考虑的图片角色：海报主视觉、封面、概念解释、流程、架构、比较、场景、独立素材。这些是检索线索，最终按内容、准确关系和实际使用区域判断。

使用条件：删减细节不能改变对象和连接关系。

构图、投影、标题体量、文字位置、留白和连接关系由模块给出。本卡不继承来源的固定主题、主体、配色数值、标志、文案或版式。按实际任务组合必要参数；无字素材不生成文字。具体喜欢与排除规则读取[当前偏好](../references/preferences.md)。
